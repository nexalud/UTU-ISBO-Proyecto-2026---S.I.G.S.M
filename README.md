## Descripción

- **Gestión documental y encuestas.** Carga de documentos por categoría, acceso del
  paciente mediante código QR y encuesta de satisfacción anónima.

- **Trazabilidad de ambulancias.** Solicitudes de traslado, asignación de vehículo,
  chofer y enfermero, y registro del estado durante todo el ciclo operativo.
